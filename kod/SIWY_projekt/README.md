## Test modelu TabPFN

Skrypt uruchamia TabPFN na przykładowych, syntetycznych danych. Domyślnie
sprawdza klasyfikację:

```bash
python src/models/train_model.py
```

Aby przetestować regresję albo oba warianty:

```bash
python src/models/train_model.py --task regression
python src/models/train_model.py --task both
```

Wyniki pokazują metrykę na wydzielonej części danych testowych. Pierwsze
uruchomienie może pobrać wagi modelu TabPFN. Przed nim zaakceptuj licencję na
https://ux.priorlabs.ai, pobierz klucz API i ustaw go w terminalu:

```bash
export TABPFN_TOKEN="YOUR_TABPFN_API_KEY"
```

Klucz ustaw jako zmienną środowiskową; nie zapisuj go w repozytorium.
